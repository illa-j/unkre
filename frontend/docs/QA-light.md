# Перевірка лендингу

Дата: 26 жовтня 2026 року.

## Підтверджено

- `npm run lint` — без помилок і попереджень.
- `npm run typecheck` та TypeScript-перевірка production build — успішно.
- `npm run build` — усі публічні маршрути статично пререндеряться.
- `TEST_BASE_URL=http://localhost:3001 npm test` — 3 з 3 smoke-тестів проходять на production-сервері.
- Перевірені server-rendered контент, H1, description, robots, соціальні метадані, sitemap та доступність усіх асетів і PNG social previews.
- У Chromium-based in-app browser перевірено ширини 320, 390, 768, 1024 та 1440 CSS px. Горизонтального overflow не виявлено; основний CTA доступний у першому екрані для перевірених розмірів.
- Перевірено sticky-сцену при скролі та реакцію на курсор; на мобільній композиції статуя зміщується праворуч, залишаючи текст відкритим.
- Hero CTA, фінальний CTA та Log in відкривають preview-діалог. Escape / Keep exploring закривають його й повертають фокус. Фоновий контент є неактивним під час native modal dialog.
- Перевірено skip-посилання: Tab → Enter переводить фокус до main.
- Переглянуто accessibility tree: одна основна область, послідовні заголовки, назви кнопок і alt-тексти; декоративна статуя прихована.
- Розрахований контраст базового muted-тексту до паперового фону — приблизно 4.93:1. Світлий фон під приміткою про кредити зберігає читабельність поряд зі статуєю.
- Зображення — локальні WebP: приблизно 116–346 KiB на файл, з responsive-доставкою через next/image. Шрифти локальні, зовнішніх CDN-запитів для них немає.
- Перевірено Open Graph PNG візуально; typography та статуя узгоджені зі сторінкою.

## Межі перевірки та запуск

- Firefox / WebKit, реальний touch-пристрій, повний screen reader-сценарій та runtime-емуляція reduced motion у цьому сеансі недоступні. Для них реалізовано відповідні fallback-стилі та семантику, але незалежної перевірки не виконано.
- Спроба browser zoom через гарячі клавіші не змінила масштаб у доступному браузері. Перевірку 200% потрібно повторити у звичайному браузері.
- LCP, INP і CLS на реальному трафіку не виміряні; повний Lighthouse / WCAG аудит не заявляється.
- Без JavaScript основний контент доступний у HTML; передбачені статичні стилі сцени та повідомлення про preview.
- Реєстрація / вхід — точки інтеграції з майбутнім бекендом. Preview не створює акаунтів і не нараховує кредити.
- Перед індексацією потрібні домен, робочі URL авторизації, фактичні умови 15 кредитів та юридичні сторінки.
