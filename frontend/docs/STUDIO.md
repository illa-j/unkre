# UNKRE Studio

Студія використовує наявний FastAPI backend. Запуск і змінні середовища:
[BACKEND.md](BACKEND.md).

| Шлях | Призначення |
| --- | --- |
| `/studio` | Моделі та сумісні LoRA з БД, prompt, reference photo, seed; кілька LoRA з окремою силою кожної; збереження й застосування пресетів; створення й polling генерації. |
| `/studio/presets` | Бібліотека пресетів: картки з моделлю, промптом, seed і кількістю LoRA; застосування в студії, перейменування, дублювання та видалення з підтвердженням. |
| `/studio/gallery` | Власні генерації з пагінацією, приклади моделей, локально збережені приклади й обране. |
| `/studio/images/[id]` | Власна генерація: статус, результат, повні налаштування (модель, prompt, negative prompt, seed, LoRA з вагами, reference images), завантаження та видалення. Для sample IDs — перегляд прикладу. |
| `/studio/loras` | Доступні LoRA та їхня сумісність із моделями з backend. |
| `/studio/credits` | Баланс, ціни, створення рахунків crypto / Stars, погашення промокодів та історія платежів. |
| `/studio/referrals` | Персональний код і посилання-запрошення, кількість запрошених, зароблені кредити та бонус друга. |
| `/studio/settings` | Профіль акаунта, вихід, локальні налаштування й експорт локального workspace. |

Дизайн зберігає графітову палітру, теплий акцент, Instrument Serif і DM Sans.
Усі налаштування генератора, включно із seed, постійно відкриті в одній формі
на десктопі й мобільному. Форма прокручується разом зі сторінкою; preview
залишається поруч на десктопі. Його висота враховує реальне положення під
шапкою, заголовком і повідомленнями сесії та обмежена 900 px; нижні
підписи й кнопки залишаються всередині панелі. Довгий контент сторінок
прокручується разом зі сторінкою. Мобільна навігація підтримує Escape, утримання
і повернення фокуса.

Порожній preview показує canvas-анімацію дифузії: частинки повільно
складаються в абстрактні форми й розсіюються. Під час надсилання, очікування
та генерації частинки збираються в щільне поле з рухомими хвилями; підписи
відображають фактичний стан без вигаданих відсотків. Готовий результат
замінює анімацію. Рух можна призупинити; `prefers-reduced-motion` залишає
статичну композицію. Прихований canvas не витрачає кадри на анімацію.

Seed має режими `Fixed` і `Randomize`. `Fixed` надсилає введене ціле число
(включно з 0), `Randomize` не надсилає seed, тому backend обирає новий для
кожного запиту. Перемикання зберігає введене фіксоване значення; посилання
з seed автоматично вмикає `Fixed`.

Завантаження reference photo доступне лише для Qwen Image 2.1. Для інших
моделей поле залишається видимим, але вимкненим із поясненням. Зміна моделі
очищує вибране фото; backend також відхиляє референси для інших моделей.

Авторизація належить `SessionProvider`; API-клієнт у `src/lib/api.ts` додає
cookies і CSRF. JWT не потрапляють до localStorage. Каталог моделей спільний
для екранів студії через `CatalogProvider`.

Посилання `/?ref=<code>` зберігає код у sessionStorage і передає його лише під
час першого входу. Після успішного входу код очищується; повторні входи не
нараховують бонус. Промокод надсилається на `POST /promos/redeem`, а після
успіху баланс перечитується з `/users/me`.

У localStorage `unkre.workspace.v1` залишаються лише чернетки, preferences,
обране та раніше збережені приклади. Reference image тримається у пам'яті
до надсилання генерації; object URLs звільняються після заміни чи unmount.
Приклади позначені окремо від справжніх генерацій.

`npm test` перевіряє API-клієнт і HTTP-сторінки; для HTTP-тестів потрібен
запущений frontend. `npm run lint`, `npm run typecheck`, `npm run build`
перевіряють реалізацію та production-збірку.
