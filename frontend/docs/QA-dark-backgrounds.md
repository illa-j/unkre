# Перевірка темного лендингу UNKRE

Дата: 26 жовтня 2026 року. Цей звіт стосується темного редизайну; попередня світла версія збережена в `QA-light.md`.

## Підтверджено

- `npm run lint`, `npm run typecheck` і `npm run build` проходять. Основна сторінка, robots, sitemap, favicon і social previews пререндеряться статично.
- `npm test` — 9 перевірок: 4 HTTP smoke-тести та 5 тестів логіки crossfade.
- HTTP-тести також проходять на production-сервері: `TEST_BASE_URL=http://localhost:3001 npm test`.
- Перевірені server-rendered заголовки й контент про Krea 2 Turbo / Raw, LoRA та reference images, видимі uncensored / NSFW і 18+, метадані, dark theme-color, crawl controls та всі асети.
- Кожна з п’яти секцій має власне зображення. Для кожного фону доступні desktop і mobile-файли; HTTP-тест перевіряє розмір менше 300 KB для кожного варіанта.
- Розміри фонових WebP: 64–145 KiB на desktop та 46–93 KiB на mobile. Шрифти й усі зображення локальні.
- У Chromium-based in-app browser перевірено 320 × 740, 390 × 844, 768 × 900, 1024 × 768 та 1440 × 900. Горизонтального overflow немає. Нижня межа hero CTA відповідно приблизно 548, 580, 705, 665 та 730 px — у першому екрані.
- Основні описи на всіх перевірених розмірах мають 16 px і міжрядковий інтервал 1.8.
- Візуально перевірено всі п’ять desktop-секцій, mobile hero, секцію моделей і фінал. Статуя зміщена від тексту; на mobile її контраст додатково зменшений.
- Під час переходу перевірені два видимі фонові шари з проміжною opacity. Після переходу лишається один непрозорий фон. Не більше двох видимих фонових зображень одночасно.
- Тести математики crossfade охоплюють початковий стан, середину переходу, завершення, швидкий стрибок до далекої секції та зворотний скрол.
- Фінальний CTA відкриває темний preview-діалог. Escape закриває його, знімає блокування скролу та повертає фокус до CTA.
- Skip-посилання перевірено через Tab → Enter: фокус переходить до main. Після виправлення positioning контейнера picture у новому прогоні немає console errors / warnings.
- Перевірено accessibility tree: один H1, окремі H2 для кожної можливості, назви моделей як H3, змістові alt-тексти, декоративні фони та статуя приховані від assistive technology.
- Dark Open Graph / Twitter preview візуально перевірено; текст прямо називає Krea 2, uncensored, LoRA та reference images.

## Межі перевірки

- Firefox / WebKit, реальний touch-пристрій і повний сценарій з окремим screen reader не перевірялися в цьому середовищі.
- Reduced motion та no-JavaScript мають статичні фони кожної секції й вимкнені transforms; перевірено код та наявність fallback у HTML. Окремий runtime-прогін із вимкненим JavaScript і емуляцією reduced motion не виконано.
- Browser zoom 200% потребує перевірки у звичайному браузері: доступний in-app browser не змінював масштаб через гарячі клавіші в попередньому сеансі.
- Контраст і читабельність перевірені візуально на оглянутих фонах та переходах; повний WCAG / автоматизований піксельний аудит не заявляється.
- LCP, INP і CLS на реальному трафіку не виміряні; бюджет асетів і статична збірка не замінюють польові вимірювання.
- Backend авторизації й генерації не входить до цієї ітерації. CTA чесно відкривають preview, поки не налаштовано реальні URL входу / реєстрації.
- До публічної індексації потрібні домен, авторизація, фактичні умови 15 кредитів і юридичні сторінки. Preview залишається noindex.
