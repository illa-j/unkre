# План редизайну лендингу UNKRE — темна версія без фонових зображень

Статус: темний редизайн реалізовано у `frontend/`. За останнім запитом фонові зображення всіх секцій прибрано разом із crossfade та їхнім завантаженням. Збережено статую, змістові приклади, CTA, SEO, accessibility і контент про uncensored / NSFW, Krea 2, LoRA й reference images. Додано схвалені ефекти: тепле світло за курсором біля статуї та плавні зміни темних відтінків між секціями. Uncensored / NSFW image generator прямо названо в hero, фінальному описі й SEO. Додано контурні написи за статуєю, тонку світлову дугу та композиції з мініатюр у hero й фіналі. Виправлено контурну типографіку через SVG із рівними стиками, mobile-сітку мініатюр та положення статуї; на телефонах декорації більше не використовують desktop-зміщення. Поточні результати перевірки — у `frontend/docs/QA.md`.

## 1. Мета та основні зміни

Оновлення контенту 27 жовтня 2026 року: у секції референсів додано два способи роботи з персонажем. Krea 2 — той самий seed та незмінний character description на початку кожного промпта для покращення схожості між кадрами, без гарантії повної ідентичності. Qwen Image 2.1 — генерація нових фото людини з reference photo та можливість додати сумісну LoRA для покращення NSFW-результатів. Назва Qwen також присутня в hero, фінальному описі й SEO. Інтеграція генерації у Studio залишається окремим етапом.

Створити темний, кінематографічний лендинг, який одразу пояснює продукт: UNKRE — платформа uncensored AI-генерації зображень для дорослих, включно з NSFW-контентом. Платформа надає доступ до Krea 2 Turbo та Krea 2 Raw, підтримує різні LoRA з прев’ю та генерацію з reference images.

Пріоритети нової версії:

1. Темна палітра замість кремового фону.
2. Темний фон із плавною зміною відтінків без фонових зображень; власна концепція кожної секції передається контентом і змістовими прикладами.
3. Природний скрол між секціями та плавний рух статуї.
4. Чітка ліва / центральна текстова колонка без сильного зсуву вправо.
5. Конкретні заголовки та короткі пояснення можливостей продукту замість абстрактних слоганів.
6. Збереження крилатої статуї, яка делікатно реагує на курсор і супроводжує скрол.
7. Мінімум керування: основний CTA в hero та фіналі, вхід і реєстрація в header.
8. Чітке позиціонування uncensored / NSFW у першому екрані з помітною позначкою 18+.

Стек залишається Next.js App Router, TypeScript, Tailwind. Реалізація — у `frontend/`. Studio, OAuth, оплата й сама генерація залишаються наступними продуктовими етапами.

## 2. Візуальний напрям і композиція

- Основа: майже чорний, графітовий, темний камінь і глибокі синьо-сірі відтінки.
- Основний текст — м’який білий; другорядний — достатньо світлий сірий, а не ледь помітний темно-сірий.
- Стриманий винний / теплий кам’яний акцент узгодити з освітленням зображень. Не будувати основну читабельність на темно-бордовому тексті на чорному фоні.
- Типографіка лишається виразною, але заголовки компактніші за попередні величезні слогани. Зміст має зчитуватися швидко.
- Основний текст — приблизно 16–18 px на desktop і не менше 16 px на mobile; комфортний міжрядковий інтервал.
- Для тексту використати спільну сітку й обмежений по ширині контейнер. На desktop вирівняти текст ліворуч у лівій / центральній частині композиції; не відсувати його до правого краю заради статуї.
- Орієнтир ширини текстової колонки: 480–600 px для заголовків, 40–55 символів у рядку для опису. Фактичні межі уточнити в браузері.
- На mobile текст має пріоритет і займає доступну ширину з нормальними відступами. Статуя підлаштовується під нього.
- Темний фон із графітовим, холодним, винним і бронзовим відтінками зберігає читабельність тексту. Тепле світло біля статуї плавно слідує за курсором.
- Фотографії мають бути пов’язані одним освітленням, кольорокорекцією та настроєм, хоча сюжет кожної секції відрізняється.
- Прибрати зайві поетичні підписи, музейні номери й декоративні фрази, які не пояснюють продукт.

## 4. Темний фон і плавний рух

- Усі секції використовують темний фон без фотографічних фонових зображень. Колір плавно інтерполюється між палітрами секцій відповідно до скролу.
- Не рендерити й не завантажувати попередні desktop / mobile фони, не використовувати crossfade.
- Секції залишаються у природному потоці; жодного scroll hijacking чи примусового snap.
- Зберегти плавні зміни положення, масштабу й освітлення статуї під час скролу.
- Текст і CTA доступні одразу, без blur, обов’язкового fade-in чи затримки появи.
- Без JavaScript та з `prefers-reduced-motion` статуя і світло статичні, фон лишається графітовим без зміни відтінків і зображень.

## 5. Постійна статуя

- Зберегти схвалену крилату фігуру та легку 2.5D-реакцію на курсор.
- Узгодити мармур зі світлом темних сцен, щоб фігура не виглядала вирізаною з білого макета. Якщо поточний асет не підходить, підготувати новий із відповідним освітленням.
- Прозорий асет статуї залишається в окремому спільному шарі. Фонових зображень немає.
- Статуя лишається на екрані при скролі, змінює масштаб, позицію й освітлення без різких стрибків.
- Під час читання її положення підлаштовується під текст. Не пересувати текст вправо й не закривати слова крилами.
- Pointer parallax лишається стриманим: приблизно 8–16 px зміщення та до 1–2 градусів нахилу, з інерцією й поверненням до нейтрального положення.
- На touch-пристроях немає реакції на курсор і запитів до гіроскопа. На маленьких екранах можна залишати лише фрагмент фігури збоку.
- Статуя декоративна, прихована від screen reader і має `pointer-events: none`.
- Зберегти поділ scroll-transform і pointer-transform, керований requestAnimationFrame, зупинку loop у прихованій вкладці та очищення listeners.

## 6. CTA та правдивість контенту

- Основний CTA — `Start creating`, лише в hero та фінальному блоці.
- Header: компактні `Log in` та `Sign up`. У секціях моделей, LoRA та референсів додаткових CTA немає.
- Зберегти зрозумілу пропозицію 15 безкоштовних кредитів без вигаданих умов.
- Наявні конфігуровані URL авторизації та preview-діалог лишаються точками інтеграції. Не імітувати успішну авторизацію.
- Пояснювати конкретні можливості одним коротким абзацом на секцію; без рекламних фраз, що не допомагають зрозуміти продукт.
- Не додавати фальшиві відгуки, кількість користувачів, ціни, характеристики моделей або гарантії генерації.
- Тарифи, промокоди, реферальні форми та повна документація Studio не входять до цього редизайну.

### Позиціонування uncensored / NSFW

- Прямо назвати `uncensored` та `NSFW` у видимому тексті hero. Не приховувати цю частину пропозиції лише у footer або SEO-метаданих.
- Пояснити NSFW як підтримку генерації контенту для дорослих і розташувати зрозумілу позначку `18+` поряд із позиціонуванням.
- Подати це як одну з основних можливостей поряд із Krea 2 Turbo / Raw, LoRA та reference images, зберігши короткий опис і просту композицію.
- Публічні ілюстрації та статуя зберігають узгоджену темну естетику. Окрема NSFW-секція чи додаткові CTA не потрібні.
- Тексти про uncensored / NSFW мають відповідати фактичним можливостям підключених моделей; до готовності інтеграції зберегти чесний статус preview.
- `18+` у hero та footer є інформаційною позначкою. Правила доступу для дорослих реалізуються у продуктовому сценарії перед використанням Studio.

## 7. SEO

- Один зрозумілий H1 із Krea 2 Turbo / Raw; окремі H2 для моделей, LoRA та reference images.
- Увесь основний текст і посилання мають бути в server-rendered HTML. Анімація статуї не повинна бути джерелом текстового контенту.
- Оновити title і description під чіткий опис продукту, а не старий поетичний слоган.
- Напрям title: `UNKRE — Uncensored Krea 2 AI Image Generator`.
- Напрям description: `Create uncensored AI images, including NSFW content for adults, with Krea 2 Turbo and Raw. Explore LoRAs and generate with reference images.`
- Включити uncensored / NSFW у метадані природно й відповідно до видимого опису продукту; не повторювати ці слова в кожному заголовку чи alt-тексті.
- Оновити Open Graph / Twitter preview відповідно до темної палітри й нового тексту. Прибрати старий світлий social preview.
- Зберегти правильний lang, favicon, конфігуровані canonical, robots та sitemap.
- Preview лишається noindex; production-індексація вмикається після готовності домену та реального сценарію реєстрації.
- Не додавати приховані SEO-тексти, keyword stuffing або вигадані reviews / offers у структуровані дані.
- Декоративна статуя прихована від screen reader; змістові приклади моделей, LoRA та reference / result мають короткі точні alt-тексти.

## 8. Accessibility

Орієнтир — WCAG 2.2 AA; не заявляти відповідність без перевірки.

- Зберегти семантичні області, послідовні заголовки, skip-посилання, keyboard navigation та робочий фокус native dialog.
- Перевірити контраст на темному фоні: щонайменше 4.5:1 для звичайного тексту і 3:1 для великого.
- Видимий focus-visible має добре читатися на темних зображеннях; не покладатися лише на темно-бордову рамку.
- Кнопки й посилання мають достатні touch-цілі; орієнтир для основних дій — 44 × 44 CSS px.
- Не зменшувати підписи до мікроскопічного розміру заради композиції.
- Перевірити zoom 200%, вузький viewport і відсутність горизонтального overflow.
- Інформація про моделі, LoRA та референси доступна без hover, анімації або взаємодії зі статуєю.
- Reduced motion повністю прибирає декоративний рух; статичний режим має виглядати завершеним.
- Фонові шари й статуя не перехоплюють кліки, скрол і фокус та не потрапляють до accessibility tree.

## 9. Продуктивність і технічна організація

- Серверний контент організовано в Hero, Models, LoRAs, Reference images та Final CTA.

- Видалити конфігурацію фонових сцен, попереднє завантаження та математику crossfade.
- Пріоритетно завантажувати статую; змістові ілюстрації використовують адаптивні розміри.
- Рух виконувати через transform / opacity без перемальовування React на кожному кадрі.
- Не використовувати важкі blur-фільтри на весь viewport чи нову WebGL-сцену.
- Зарезервувати місце під змістові зображення та пари reference / result, щоб не створювати layout shift.
- Перевірити lint, TypeScript, production build та HTTP smoke-тести після зміни.
